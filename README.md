# Business Management System

Flutter + Supabase ERP app. Phase 1 is the project foundation only.

Living notes: [documentation/PROJECT.md](documentation/PROJECT.md)

## Run

Paste your Supabase URL and anon/publishable key in `lib/config/app_config.dart`, then:

```bash
flutter pub get
flutter run
```

Android Studio: open the project and press Play. No extra run arguments are needed.

Never put a service-role key in the Flutter app.
